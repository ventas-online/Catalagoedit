# Onboarding de cliente

## Datos mínimos
- Nombre del negocio
- Logo
- WhatsApp comercial
- Instagram opcional
- Categorías
- Productos
- Precios
- Descripciones
- Fotos
- Moneda

## No solicitar
- Contraseñas
- Códigos 2FA
- Tokens
- Claves API
- Documentos personales innecesarios
- Datos bancarios por chat

## Flujo
1. Recibir datos.
2. Validar campos.
3. Preparar fotos.
4. Importar productos.
5. Personalizar marca.
6. Probar carrito y WhatsApp.
7. Probar móvil.
8. Publicar.
9. Entregar enlace y QR.
10. Confirmar aceptación.
