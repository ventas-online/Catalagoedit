# Playbook de venta y entrega

## 1. Antes de vender

- Enseña la demo publicada.
- Explica que el catálogo es personalizable.
- Define cantidad de productos, fotos, colores, logo, WhatsApp y dominio.
- Define si el cliente quiere solo catálogo o también mantenimiento.

## 2. Paquetes sugeridos

### Básico
Catálogo, productos, categorías, fotos y WhatsApp.

### Profesional
Básico + carrito, favoritos, filtros, QR, personalización y optimización móvil.

### Premium
Profesional + dominio, integración de pagos/backend y funciones a medida.

El precio final debe depender del trabajo, número de productos, personalización y soporte.

## 3. Datos que debes pedir al cliente

- Nombre comercial
- Logo en buena calidad
- Colores o referencia visual
- WhatsApp comercial
- Moneda
- Lista de productos
- Precios
- Categorías/marcas
- Fotos autorizadas para publicar
- Texto de presentación
- Horarios, zonas de entrega y políticas
- Dominio, si ya tiene uno

Nunca pidas contraseñas por chat. Si necesitas acceso, usa un método de colaboración o invitación de GitHub.

## 4. Flujo de producción

1. Duplica la plantilla.
2. Crea un repositorio independiente para el cliente.
3. Sustituye configuración y productos.
4. Sustituye imágenes y logo.
5. Personaliza estilos y textos.
6. Prueba el catálogo en móvil y escritorio.
7. Activa GitHub Pages.
8. Prueba QR, carrito y pedido.
9. Conecta el dominio si corresponde.
10. Entrega URL y repositorio al cliente.

## 5. Regla de propiedad

Siempre que sea posible, el repositorio del cliente debe pertenecer al cliente y tú debes trabajar como colaborador/desarrollador. La plantilla maestra permanece en tu cuenta.

## 6. Mantenimiento mensual

Puedes ofrecer actualización de productos, precios, banners, imágenes, correcciones y soporte. Define por escrito qué incluye el mantenimiento y qué se cobra aparte.
