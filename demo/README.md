# Demo comercial

Esta carpeta contiene únicamente datos ficticios para probar CatalogoEdit sin tocar el catálogo original Lovely Girl.

## Objetivo
Validar el flujo completo del MVP:

1. Abrir catálogo.
2. Buscar y filtrar productos.
3. Abrir detalle.
4. Añadir y modificar carrito.
5. Completar checkout.
6. Enviar pedido cuando WhatsApp esté configurado.
7. Compartir mediante QR.
8. Instalar como PWA.

No introducir aquí datos personales, números reales, contraseñas ni API keys.
