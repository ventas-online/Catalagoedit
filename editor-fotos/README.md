# Editor de Fotos para Catálogo

Herramienta local para preparar imágenes de productos antes de incorporarlas a una tienda.

## Principios
- Procesamiento local por defecto.
- Sin API obligatoria.
- Sin claves secretas en frontend.
- Originales siempre intactos.
- Optimización orientada a móvil y web.

## Funciones objetivo
- Recorte y centrado
- Brillo, contraste y saturación
- Nitidez moderada
- Fondo blanco/transparente
- Redimensionado
- JPG/PNG/WebP
- Procesamiento por lotes
- ZIP de resultados
- Eliminación de fondo con modelo local cuando la integración sea estable y compatible con la licencia

## Estado
La edición básica puede funcionar sin servidor. La eliminación automática de fondo con IA se integra como módulo separado para no introducir dependencias ni costes innecesarios.
