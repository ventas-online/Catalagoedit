# PWA / instalación móvil

## Objetivo
Que el catálogo pueda instalarse desde un navegador compatible como aplicación en la pantalla de inicio.

## Requisitos
- manifest.webmanifest correcto
- display standalone
- nombre y short_name de marca
- iconos adecuados
- start_url coherente con GitHub Pages
- Service Worker registrado con ruta correcta
- HTTPS
- interfaz responsive

## Pruebas
1. Abrir URL pública en Android.
2. Comprobar que el navegador ofrece instalación o añadir a pantalla de inicio.
3. Instalar.
4. Abrir desde el icono.
5. Verificar carrito, imágenes y WhatsApp.
6. Verificar actualización después de cambios de versión.
