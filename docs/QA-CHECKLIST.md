# Checklist QA antes de vender

## Móvil
- [ ] Navegación sin desbordamientos
- [ ] Botones táctiles claros
- [ ] Imágenes uniformes
- [ ] Carrito visible y usable

## Compra
- [ ] Añadir producto
- [ ] Aumentar/disminuir cantidad
- [ ] Eliminar producto
- [ ] Subtotal/total correctos
- [ ] Pedido WhatsApp ordenado
- [ ] Carrito vacío funciona

## Catálogo
- [ ] Búsqueda
- [ ] Filtros
- [ ] Categorías
- [ ] Detalle de producto
- [ ] Productos sin imagen manejados
- [ ] Productos sin precio manejados

## PWA
- [ ] Manifest válido
- [ ] Iconos
- [ ] Instalación en Android compatible
- [ ] Service worker sin errores
- [ ] Actualización de versión controlada

## Seguridad
- [ ] Sin secretos en código público
- [ ] Sin documentos personales
- [ ] Sin claves API
- [ ] Datos de cliente separados

## Publicación
- [ ] HTTPS
- [ ] Enlace final probado
- [ ] QR probado
- [ ] Cliente aprueba contenido
