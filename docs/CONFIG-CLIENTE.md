# Configuración por cliente

## Datos editables
- nombre comercial
- logo
- colores
- WhatsApp
- Instagram/Facebook opcionales
- moneda
- categorías
- productos
- textos legales

## Datos que no deben estar en frontend público
- contraseñas
- tokens privados
- API keys
- credenciales de pago
- secretos de backend

## Entrega
Cada cliente debe tener su propia configuración y, cuando corresponda, su propio repositorio. La plantilla maestra no debe contener datos personales del cliente.
