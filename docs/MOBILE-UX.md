# UX móvil

## Principios
- Mobile-first.
- Acciones primarias visibles.
- Áreas táctiles cómodas.
- Evitar modales innecesarios.
- Carrito accesible sin tapar productos.
- Formularios cortos y con validación inmediata.
- Mensajes claros para carga, éxito, error y sin resultados.

## Catálogo
Inicio → categorías → búsqueda/filtros → producto → carrito → resumen → WhatsApp.

## Editor
Subir → previsualizar → editar → comparar → guardar → siguiente. En lote: cola → progreso → errores/reintento → ZIP.

## Accesibilidad
Contraste suficiente, foco visible, etiquetas para controles, texto alternativo y navegación por teclado cuando corresponda.
