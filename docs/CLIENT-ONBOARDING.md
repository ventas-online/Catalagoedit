# Onboarding de clientes

## Datos necesarios
- Nombre comercial
- Logo
- Categorías
- Productos
- Precios
- Fotos
- Descripciones opcionales
- WhatsApp comercial
- Redes sociales opcionales
- Preferencias de colores

## Nunca solicitar
- Contraseñas
- Códigos 2FA
- Claves API
- Datos bancarios innecesarios
- Documentos personales que no sean imprescindibles

## Entrega
1. Recibir información.
2. Validar productos e imágenes.
3. Preparar fotos.
4. Cargar catálogo.
5. Configurar carrito y WhatsApp.
6. Revisar móvil/desktop.
7. Cliente aprueba.
8. Publicar.
9. Entregar enlace y QR.
10. Registrar versión y soporte.
