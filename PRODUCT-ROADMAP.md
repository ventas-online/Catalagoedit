# Catalagoedit — Roadmap de producto

## Principio
Producto móvil-first, limpio, rápido, accesible, privado por defecto y reutilizable para crear catálogos comerciales.

## Fase 1 — Producto vendible
- [x] Catálogo responsive
- [x] Carrito y pedido por WhatsApp
- [x] Búsqueda, filtros y favoritos
- [x] QR/PWA base
- [x] Biblioteca de nichos
- [x] Editor de foto básico documentado
- [ ] Auditoría final de UX móvil
- [ ] Prueba completa de carrito/pedido
- [ ] Checklist de publicación

## Fase 2 — Producción rápida
- [ ] Importador CSV/JSON de productos
- [ ] Validador de precios, imágenes y campos obligatorios
- [ ] Generador de demo por nicho
- [ ] Procesamiento de imágenes por lotes
- [ ] Exportación ZIP lista para catálogo
- [ ] Generación automática de estructura de productos

## Fase 3 — Editor avanzado
- [ ] Eliminación de fondo con modelo cuya licencia permita uso comercial
- [ ] Comparación antes/después
- [ ] Corrección manual de resultados
- [ ] Presets por nicho
- [ ] Procesamiento local prioritario

## Fase 4 — PWA y calidad
- [ ] Instalar en Android/iOS compatible
- [ ] Iconos y splash coherentes
- [ ] Offline robusto para recursos esenciales
- [ ] Estados de carga, error y vacío
- [ ] Accesibilidad de teclado y lectores de pantalla
- [ ] Rendimiento y compresión

## Fase 5 — Seguridad y entrega
- [ ] Cero secretos en repositorios públicos
- [ ] Datos por cliente aislados
- [ ] Backend separado si alguna integración requiere secreto
- [ ] Política de privacidad y condiciones básicas
- [ ] Checklist QA antes de publicar
- [ ] Repositorio propio para cada cliente

## Fase 6 — Automatización
- [ ] Formulario de onboarding
- [ ] Configuración por cliente
- [ ] Duplicación controlada de plantilla
- [ ] Flujo de publicación
- [ ] Registro de versiones
- [ ] Mantenimiento y actualizaciones

## Calidad mínima antes de vender
No marcar una función como terminada solo porque exista el archivo. Debe funcionar en móvil, manejar errores, conservar datos, no exponer secretos y pasar una prueba real de extremo a extremo.
